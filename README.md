# 🛒 E-Commerce Orders Data Analysis

**NPower Canada | AI & Data Analytics Program**
**AIDA20263T3A | Scrum Group 5 | September 2026**

## 📌 Project Overview

This project analyzes an **E-Commerce Orders dataset** to identify patterns in **sales, revenue, customers, products, payment methods, and order status**.

The project follows an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → EDA → Visualization → Interactive Dashboard → Insights**

## 🎯 Objectives

* Clean and prepare raw e-commerce data
* Perform exploratory data analysis
* Identify sales and revenue trends
* Analyze products, customers, payments, and order status
* Present findings through an interactive dashboard
